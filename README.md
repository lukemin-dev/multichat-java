# Multichat Java

Java Socket API와 멀티스레딩을 사용해 구현한 실시간 채팅 시스템 프로젝트 정리 저장소입니다.

## 프로젝트 목적

여러 클라이언트가 동시에 접속하는 환경에서 메시지 송수신, 연결 종료, 로그 추적을 안정적으로 처리하는 흐름을 학습하기 위해 진행했습니다.

## 핵심 주제

- Java Socket 기반 클라이언트/서버 통신
- 클라이언트별 스레드 처리
- 메시지 유형 구분
- 수신 버퍼 처리
- 로그 기준 통일을 통한 디버깅

## 문제 해결 포인트

- 긴 메시지가 여러 번에 나뉘어 수신될 때 데이터가 깨지는 문제를 분석했습니다.
- 스레드 ID, 타임스탬프, 이벤트 유형을 로그에 남겨 어느 연결에서 문제가 발생했는지 추적했습니다.
- 메시지 단위를 명확히 처리하기 위해 헤더와 페이로드 기준의 프로토콜 설계를 검토했습니다.

## 면접 대비 문서

프로젝트 설명 흐름과 면접 답변 포인트는 [`docs/interview-notes.md`](./docs/interview-notes.md)에 정리했습니다.

## 다시 한다면

- 직접 스레드를 생성하는 방식 대신 Thread Pool을 적용
- Java NIO 기반 비동기 소켓 처리 검토
- 메시지 프로토콜 테스트 코드 추가
- 클라이언트 재접속과 예외 복구 흐름 보강
